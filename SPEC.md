# WW2 Channel Air War: Spec (Godot 4.3, GDScript)

Arcade cell-shaded WW2 flight game over Southern England, the English Channel, Northern France and Belgium, 1940-44.
Player picks Allies or Axis. Modes: dogfight, bombing run, ground attack/strafing, historical missions, free flight.
Feel: easy, fast, forgiving. NOT a hardcore sim.

## SHARED CONVENTIONS (all agents must follow)

- No photo textures. All art is low-poly toon. Placeholder models must be generated in code from primitives (CSG / ArrayMesh / MeshInstance3D) so the game is always playable with zero imported assets. Any imported asset must be CC0/CC-BY and listed in `ATTRIBUTION.md`.

## WORLD COORDINATE CONTRACT (critical)
Map is compressed 1:10 horizontally. Origin = lat 50.30, lon 0.00. Godot axes: +X east, -Z north, +Y up.
```
world_x =  (lon - 0.0)  * 111320.0 * cos(radians(50.3)) / 10.0
world_z = -(lat - 50.3) * 110540.0 / 10.0
world_y =  elevation_m * 2.0          # 2x vertical exaggeration
```
Playable bounds: lat 48.9 .. 51.7, lon -4.6 .. 4.7.
`WorldCoords` autoload (`scripts/world_coords.gd`) exposes `latlon_to_world(lat, lon) -> Vector3` (y=0), `world_to_latlon(Vector3) -> Vector2`, and constants for bounds and the vertical scale. All code uses it. Never re-implement the formula.

## DATA CONTRACT (produced by /tools, consumed by game)
- `data/locations.json`: `{ "airfields":[{id,name,side:"RAF"|"Luftwaffe",lat,lon,heading_deg,runway_len_m}], "cities":[{id,name,lat,lon,size:1-5,landmark?}], "features":[{id,name,type:"cliff"|"beach"|"battery"|"river"|"forest"|"landmark",lat,lon,radius_m?}], "targets":[{id,name,type,lat,lon,side_owner}] }`
- `data/heightmap/region_height.png` (16-bit grayscale, north-up, covers the playable bounds; 0 = sea level / below, 65535 = 1000 m) + `data/heightmap/region_meta.json` `{width,height,lat_min,lat_max,lon_min,lon_max,max_elev_m:1000,sea_level_value:0}`.
- `data/osm/{roads,rails,rivers,coast,woods,towns}.json`: simplified polylines/polygons in lat/lon, small enough to load in <2s (decimated). `rivers.json` is the OSM waterway network (river/canal/stream classes), drawn as real water geometry (Phase 1).
- `data/industry_1940.json`: `{ "sites":[{id,name,kind,lat,lon,size,team}] }` — hand-authored 1940s industry, `kind` ∈ `gasworks|colliery|mill|brewery|power_station|shipyard|dockyard|goods_yard|engine_shed|waterworks|cement_works|staithes`. `data/docks_1940.json`: `{ "piers":[...], "docks":[...] }` (same keys; `kind` ∈ `pleasure_pier|harbour_pier|basin|lock|drydock|shipyard`). `data/landmarks_1940.json`: `{ "landmarks":[{id,name,lat,lon,city,kind,scale,from_air,era_note}] }` — the 42 new landmark silhouettes. The 1940 `*_1940.json` files are hand-authored (generated by `tools/make_industry_1940.py`, no third-party licence); `rivers.json` is OSM/ODbL (see ATTRIBUTION.md).
- Scripts must run offline with a procedural fallback (noise heightmap shaped by a hand-authored coastline polygon) if the DEM/OSM downloads fail.
- Fallback/synthetic OSM is ACCEPTED, not a bug or a TODO: Kent (tile 21) and Pas-de-Calais (tile 16) roads use the synthetic fallback (those Overpass tiles never downloaded), and the expanded NE map area's rails/coast/woods/towns are synthetic or missing. `data/osm/_source.json` records `overpass` vs `fallback` per layer; re-running the fetchers is optional, never required.

## VISUAL STYLE
- Reusable toon shader `shaders/toon.gdshader` (stepped light ramp 3-4 bands, rim light, albedo colour/uniform, optional ramp texture). Applied to all aircraft, vehicles, buildings, props.
- Outlines: inverted-hull outline material `shaders/outline.gdshader` (second pass / next_pass). Provide a global toggle in GameState.
- Terrain: banded toon shader, colours by height/slope (chalk cliffs, grass, farmland patchwork, sand, rock).
- Water: stylised shader, flat colour bands, scrolling foam lines at shore.
- Clouds: toon-shaded puffs via MultiMesh + cloud decks. Sky/fog via WorldEnvironment. Optional vignette/grain post.
- Muted painterly palette: olive greens, chalk white, grey sea, brown fields.

## WORLD CONTENT
Real locations (see data contract). RAF airfields: Biggin Hill, Hawkinge, Manston, Tangmere, Kenley, Northolt, Duxford, Debden, Westhampnett, Lympne, Hornchurch. Luftwaffe: Calais-Marck, Cap Gris-Nez, Abbeville-Drucat, Caen-Carpiquet, Cherbourg-Maupertus, Merville, Saint-Omer, Lille-Nord, Brussels-Evere, Antwerp-Deurne. Each airfield: runway with markings, hangars, tower, parked aircraft, wind sock; player can take off/land/rearm/repair.
Cities/towns: London, Dover, Folkestone, Portsmouth, Southampton, Brighton, Plymouth, Canterbury, Calais, Dunkirk, Boulogne, Dieppe, Le Havre, Rouen, Caen, Cherbourg, Bayeux, Amiens, Lille, Arras, Ostend, Bruges, Ghent, Brussels, Antwerp. Landmarks: Dover Castle, Tower Bridge, Big Ben, church steeples, Mont Saint-Michel.
Features: White Cliffs of Dover, Seven Sisters, D-Day beaches (Utah, Omaha, Gold, Juno, Sword), Dunkirk beaches, Thames/Seine/Somme, New Forest, Ardennes.
New geography, towns, waterfronts, industry and landmarks (all procedural, streamed; Phases 1-5):
- **Real rivers:** `data/osm/rivers.json` is drawn as a terrain-hugging water ribbon (`scripts/ground/river_mesh.gd`, `class_name RiverMesh`) streamed per tile like roads, with `shaders/river.gdshader` (flow scroll along the arc-length UV, silt banks). `tools/carve_rivers.py` lowers the DEM along each course so the ribbon sits in a real valley and the banks read from the air; `RiverMesh` also works un-carved (drapes on `GroundKit.ground_y`). `RiverMesh.ensure_loaded()` sets the terrain shader global `real_rivers` so the painted rivers retire while geometry is present, and scatter keeps houses/trees/hedges/farms out of the channel (`near_river`).
- **Street-driven towns:** `Scatter.make_town()` (via `Scatter.town_layout()`) lays terraces along the real street tangents (`RoadMesh`), breaking at junctions, with districts by radius/size (commercial core, inner terraces, suburban semis/cottages, industrial fringe), a civic core for large towns (market square, town hall, railway station on the nearest rail), and a waterfront that faces the river/coast and thins to a quay edge.
- **Piers & docks:** `data/docks_1940.json` sites (pleasure piers, harbour piers, dock basins, locks, dry docks/shipyards) are streamed by `_register_docks()` and built by typed `WorldFeatures` builders (`build_pleasure_pier`, `build_dock_basin`, `build_drydock_shipyard`, `build_river_quay`, `build_fishing_harbour`), each snapped to the nearest shoreline.
- **Industry v2:** `data/industry_1940.json` drives `scripts/ground/industry_kit.gd` (`class_name IndustryKit`) — gasworks, colliery, mill, brewery, power station, shipyard/dockyard, goods yard, engine shed, waterworks, cement works, staithes — oriented along the nearest rail (or river) with a rail siding stub; destructible kinds are added to `GroundStructure`.
- **Landmarks & skylines:** `scripts/ground/landmarks.gd` `build()` covers ~70 ids (42 period silhouettes in `data/landmarks_1940.json`: Battersea Power Station, Tower of London, Rochester Castle, Lille Hôtel de Ville, Brussels Palais de Justice…), wired into town skylines via `cities[].landmark` in `data/locations.json`, with harbour works pinned to sea level.
Ground/war assets (all animated and instanced where repeated): tanks (Sherman, Panzer IV, Tiger), troop columns, trucks, artillery on Path3D along roads; Atlantic Wall bunkers, coastal batteries (Longues-sur-Mer), pillboxes, beach obstacles, wire, trenches; AA guns (88mm, Bofors) with tracers/flak bursts, searchlights (sweep at night, track aircraft), barrage balloons, Chain Home radar; destroyers, freighters, landing craft, fishing boats with wakes; farms, barns, windmills, hedgerows, patchwork fields, cattle; steam trains on rail splines (strafable), bridges, rail yards, harbours, factories, oil depots; burning wrecks, craters, smoke columns, persistent fires, destroyed-building swaps.

## WEATHER / TIME
- `TimeOfDay` autoload: dawn/noon/dusk/night presets, rotating sun/moon, sky+fog+grade presets, stars, cockpit dimming. API: `set_time(hour: float)`, `time_scale`.
- `WeatherManager` autoload: clear, scattered, overcast, rain, storm (lightning), fog/haze; transitions mid-mission; affects visibility and AI accuracy; GPUParticles3D rain; cloud decks; sea fog. API: `set_weather(name, blend_time)`, signal `weather_changed`.

## GAMEPLAY
- Aircraft are Resources (`data/aircraft/*.tres`, class `AircraftStats`): speed, turn rates, durability, ammo, bomb load, model path/scene, side.
  Allies: Spitfire, Hurricane, Typhoon, Mosquito, P-51, P-47, Lancaster, B-26. Axis: Bf 109, Fw 190, Ju 87, He 111, Ju 88, Me 262. Correct national markings (roundel, Balkenkreuz).
- Flight model (arcade): pitch/roll/yaw, throttle, boost + cooldown, flaps, simple stall, gentle crash, auto-level assist toggle. InputMap with keyboard + gamepad. Chase cam with smooth follow, speed FOV, shake.
- Weapons: MG/cannon with tracers + sparks, bombs with ballistic arc + bombsight, rockets. Pooled.
- Damage: smoke/fire trails, wing loss, parachuting pilots, toon starburst explosions.
- AI: state machines (patrol/intercept/attack/evade), wingmen, bombers on Path3D waypoints, difficulty scaling.
- Cameras: chase, cockpit (toon, working gauges), kill-cam.
- HUD: alt, speed, compass, ammo, bombs, health, minimap/radar (real map, labelled towns/airfields), objective marker, weather+time readout. Menus: start (side, aircraft, mission, weather, time), pause, results.
- Modes: dogfight waves; bombing run (real targets); ground attack (trains/convoys/tanks); historical missions (Battle of Britain over Kent, Dieppe 1942, D-Day 6 June 1944, Dunkirk cover, bombing Antwerp/Lille/Le Havre); free flight.
- Progression: score, medals, unlocks, saved via SaveSystem (user://).
- Audio: engine drone (pitch by throttle), guns, explosions, flak, wind, rain via AudioStreamGenerator procedural fallback; bus layout music/SFX/ambience; mute + volume.
