# North American P-51D Mustang — dimensions & stations

Model id `p51`, built by `tools/models/data/p51.py` via `tools/models/build_all.py`.
Frame: metres, origin at the CG station, **nose toward +Y**, up +Z, right +X (glTF maps that onto
Godot's −Z forward). Deterministic — no RNG, so a rebuild is byte-identical.

Note on height: the DCS manual quotes "height (tail down) 12 ft 2 in" while Wikipedia quotes 13 ft 8 in.
The model is gated to 4.17 m (13 ft 8 in, the overall standing height). The `bounds_report` helper in
`kit.py` treats height as stance-dependent and gates only length/span; this file additionally gates height
because the brief asks for a per-axis comparison.

## Wing planform (laminar flow)

Straight tapered planform, LE swept back 3° 35′, thin laminar sections, gently squared tips.
Spanwise stations `(x, chord, y_le, z_offset, thickness_ratio)`, root → tip (`HALF = 5.64`):

```
xs     = [0.34, 0.80, 1.40, 2.10, 2.80, 3.45, 4.05, 4.60, 5.05, 5.40, 5.64]
chord  = 2.64 - 1.37 * (x / HALF)
y_le   = 0.72 - 0.0626 * x            # 3°35′ sweep
z_off  = -0.20 + 0.49 * (x / HALF)    # 5° dihedral
thick  = 0.15 - 0.030 * (x / HALF)    # 66-215 -> 66-212
airfoil camber 0.025, n = 22
```

## Gear, prop, markers

* Main gear pivots `GearL/GearR` at x = ±1.805 (tread 3.61), y = 0.42, z = −0.42;
  leg length is solved so the 0.343 m tyres land on the height-gate ground line (≈1.20 m).
* Tail wheel: `TailWheel` at y = TAIL+1.05, 0.32 m tyre.
* Propeller: 4 blades, radius 1.70, spinner r 0.34, hub at y = NOSE − 0.374.
* `MuzzleL/MuzzleR` at (±2.35, 0.12, −0.06) (three .50s per wing); `CockpitEye`/`CockpitMount` at
  (0, −0.10, 0.86). Decals via `kit.markings("USAAF", ...)`.

## Notes / caveats

* `kit.radiator(...)` is called with `mouth=False`: the kit's intake plate passes `cy=x`, which places the
  mouth at z = x (an argument-order slip in the shared kit). The housings alone read correctly.
* Height is a "standing" (gear-down) figure — the model is posed level, not nose-down, so that the
  length/span bbox gate stays clean. The tail wheel hangs on a realistic short strut.
* Only published geometry is used; no third-party mesh was read or converted.
