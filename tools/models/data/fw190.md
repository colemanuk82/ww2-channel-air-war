# Fw 190A-8 — researched dimensions, sources and station tables

Built by `tools/models/data/fw190.py` (`build()`, no args). Units: metres; nose **+Y**, up **+Z**,
right **+X**. Origin at mid-length, level attitude, gear down. Deterministic — no RNG.

Height = fin top above the main-wheel contact plane, level attitude. The propeller is excluded from
the bounding box (its 3.30 m disc would otherwise set the height); see the Bf 109 notes for the same
convention. Wikipedia's A-8 spec sheet lists 3.15 m — the DCS manual, warbirdsresourcegroup, aeropedia
and airpages all give 3.95/3.96 m, so the majority reading is used.

## Nodes emitted

`Body` > `Fuselage`, `Wing`, `Tailplane`, `Fin`, `Canopy`; top level: `Propeller` > `Blades` +
`Spinner` + `PropDisc`, `GearL`, `GearR`, `Pilot`, `CockpitEye`, `MuzzleL`, `MuzzleR`,
`CockpitMount`, `Decals`. Extras: `FanRing` + `FanHub` (the BMW 801 cooling-fan ring behind the
spinner), `GunCowlL/R` (2 × MG 131), `GunRootL/R` (MG 151/20 wing-root cannon), `Exhaust0/1`,
`TailWheel`, `TailLeg`.

## Known compromises

* The A-8's outer-wing MG 151/20 pair is represented by the wing-root cannon only (the muzzle
  markers sit on the root guns); the outer guns were a common field modification and are not
  modelled separately.
* Tailplane span is published; tail chords, the fin chords and the 5° dihedral are scaled from
  three-views — no dimensional table was found for them.
* No swastika anywhere: `kit.markings` substitutes a plain fin band for the Luftwaffe.
