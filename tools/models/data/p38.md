Model id `p38`, built by `tools/models/data/p38.py` via `tools/models/build_all.py`.

## Wing planform

The P-38 wing is very nearly constant-chord with a straight leading edge and a short, only gently
tapered tip — modelled as such (`HALF = 7.925`, root 2.30 m, tip 1.54 m ≈ mean chord 1.92 m).
Spanwise stations `(x, chord, y_le, z_offset, thickness_ratio)`, root → tip:

```

chord  = 2.30 - 0.76 * (x / HALF) ** 1.25

z_off  = -0.18 + 0.485 * (x / HALF)    # 3.5° dihedral

```

## Props, gear, cooling, armament, markers

* **Props (handed):** `Propeller` (left, +X) and `Propeller2` (right, −X), each 3 blades, radius 1.755,
  spinner r 0.40. Each blade is twisted ±22° about its own span (`rotation_mode 'YXZ'`), so the two
  engines counter-rotate. The secondary's children are named `Blades2` / `Spinner2` / `PropDisc2` /
  `PropBlade2_*` / `BladeTip2_*`.
* **Tricycle gear:** `GearL/GearR` (0.457 m mains) at x = ±2.52, y = 0.35 — nose wheel forward;
  `GearN` (0.343 m) under the nacelle at y = 1.85. No tail wheel.
* **P-38J chin intercoolers:** `ChinL/ChinR` under the boom fronts; boom-side radiators `BoomRadL/R`.
* **Nose armament:** four .50 `NoseGun` + one 20 mm `Cannon`, barrel tips flush with the nose.
* `MuzzleL/MuzzleR` at (±0.28, 4.05, 0.10); `CockpitEye`/`CockpitMount` at (0, −0.55, 0.72).
  Decals via `kit.markings("USAAF", ...)`.

## Notes / caveats

* `kit.radiator(...)` uses `mouth=False` — the kit's intake plate passes `cy=x`, which puts the mouth at
  z = x (an argument-order slip in the shared kit); the housings read correctly on their own.
* The boom centreline was set from the published main-gear track (5.03 m) → x = ±2.52, giving the P-38's
  characteristic long outer wing panels.
* Height is the on-gear figure; the model is posed level so the length/span bbox gate stays clean.
