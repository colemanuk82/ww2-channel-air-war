# Me 262A-1a — researched dimensions, sources and station tables

Built by `tools/models/data/me262.py` (`build()`, no args). Units: metres; nose **+Y**, up **+Z**,
right **+X**. Origin at mid-length, level attitude, gear down. Deterministic — no RNG.
Twin Jumo 004 nacelles under the wings, swept wing, tricycle gear, **no propeller**.

`ZwiebelL/R`, `PylonL/R`, `GunLow0/1` + `GunUp0/1` (4 × MK 108 in the nose), `Slat0/1`.

## Known compromises

* **No propeller and no `PropDisc`/`Blades`/`Spinner`.** `aircraft.gd` guards every prop lookup
  (`if _prop:`, `if _prop_blades:`, `if _prop_disc:`), so the Empty `Propeller` at the nose is
  harmless; the jet sound/effects layer is the engine's business.
* `GearN` (nose gear) is not in the node contract and is therefore static — `aircraft.gd` retracts
  only `GearL`/`GearR`. For a tricycle aircraft the nose leg should really retract too.
* The nacelle is built from the published *engine* diameter plus cowl clearance; no published
  nacelle outer-dimension table was found.
* Main-wheel track, tailplane span, fin/tail chords and dihedral are scaled from the 3-view.
* No swastika anywhere: `kit.markings` substitutes a plain fin band for the Luftwaffe.
