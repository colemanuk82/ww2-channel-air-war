# Douglas A-20G Havoc — 1:1 model dimensions

Geometry: `tools/models/data/a20.py` (build() — kit.py primitives only). Metres, nose toward +Y,
origin at the CG station; the glTF export maps Blender +Y onto Godot −Z.

Type modelled: **A-20G-20-DO**, **solid six-gun nose**, **single fin-and-rudder**, Martin 250CE dorsal
turret + ventral gun + two waist positions, tricycle gear with the main wheels under the under-slung
nacelles, 3-blade props.
