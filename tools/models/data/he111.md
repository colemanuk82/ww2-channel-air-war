# Heinkel He 111 H — dimensions & authoring stations

Type: twin-engine medium bomber (He 111 H-6 / H-16, Jumo 211). Nation: Luftwaffe.
Authored in metres, nose toward +Y, up +Z, right +X (glTF export maps +Y onto Godot's -Z).
