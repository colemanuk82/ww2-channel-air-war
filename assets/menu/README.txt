Drop the menu background images here.

Any .jpg / .png / .webp files in this folder are loaded by scripts/menu_background.gd and cycled
behind the start menu with a crossfade. They sort by filename, so naming them 01.jpg .. 06.jpg
controls the order. Recommended size: 1920x1080 or larger, landscape.

If this folder is empty the start menu falls back to the live 3D menu camera.
