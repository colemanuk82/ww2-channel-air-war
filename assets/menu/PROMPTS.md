# Menu / loading background paintings

Drop finished images into this folder. Any `.jpg`, `.png` or `.webp` here is picked up automatically by
`scripts/menu_background.gd` for both the start menu and the loading screen; filenames control the cycle order.
The current set is 2752 x 1536 (16:9) and the menu crops with `KEEP_ASPECT_COVERED`, so 16:9 or wider is ideal.

**Style rules for every new painting**

- Painterly WW2 aviation illustration, visible brushwork, cinematic lighting, rich but muted period palette.
- Historically plausible aircraft, markings and landscapes; no modern objects, text, logos or watermarks.
- Keep the subject on the right or centre and leave the left third relatively open/darker: the start menu's
  briefing column sits over that side.
- No hard rectangular edges or blank borders; let fields, cloud and terrain run to the frame edge.
