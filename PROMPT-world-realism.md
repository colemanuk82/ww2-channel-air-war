# PROMPT: world realism (no toon)

Owner (2026-10-10): **"get rid of the toon aesthetic and aim for more real life assets"** ... "then work on world
assets to make more realistic with no toon effect". The aircraft already made the switch (real PBR materials,
procedural camo, no outline pass). The world is still cel-shaded: every building, road, tree and prop goes
through `ToonUtil.make_toon()` -> `shaders/toon.gdshader` + an inverted-hull `outline.gdshader` next_pass.

## Why this is one change and not a hundred
~100 procedural "kit" scripts (ground_kit, rural_kit, industry_kit, rail_kit, canal_kit, port_clutter_kit,
airfield_*, military_depth_kit, ...) all build their meshes through `ToonUtil.make_toon(color, opts)` and
`ToonUtil.make_mesh(mesh, color, opts)`. Re-pointing that one factory at realistic materials upgrades the whole
world without editing a single kit script. Keep the signature and the option names so nothing breaks.

## Phases
| # | Phase | Deliverable |
|---|---|---|
| W1 | Material system | `tools/make_world_textures.py` (procedural, tileable texture set + manifest) + `shaders/world_pbr.gdshader` (triplanar, weathered, real roughness/metallic) + `ToonUtil.make_toon` re-pointed at it, outline OFF by default |
| W2 | Terrain | `shaders/terrain.gdshader`: realistic field/soil/rock/crop/grass blending by slope + altitude + noise, no flat colour bands, no toon ramp |
| W3 | Vegetation + water | leaf-colour realism on the scatter species, canopy cards, water/coastline shaders |
| W4 | Lighting + atmosphere | tone mapping (AgX/ACES), sun colour/energy, fog, sky, ambient occlusion, no rim-light look |
| W5 | Effects | smoke/fire/dust that read as real smoke rather than stylised puffs |

## Hard rules
- Textures are generated by our own Python (no third-party/ripped art), deterministic, tileable, 1024x1024.
- Triplanar projection: the world meshes are procedural and have no usable UVs.
- No toon ramp and no inverted-hull outline anywhere in the world (the aircraft team_outline IFF tint is a
  separate gameplay feature and stays).
- The test gate must stay green: `<godot exe> --headless --path F:/ww2_dlss scenes/tests.tscn` ->
  `TESTS OK (N passed, 0 failed)`. Only the parent process runs Godot (one instance at a time).
